# 要件定義書（Windows防犯カメラ）

## 1. 対象機器
- USB接続のWebカメラ1台のみに対応する（MVP）。複数カメラ同時監視は対象外。

## 2. 機能要件

### 2.1 録画
- 常時録画は行わず、**動体検知時のみ**録画を行う。
- 録画ファイルはローカルディスクに保存する。

### 2.2 動体検知
- フレーム間の差分等により動体を検知する。
- 検知感度は**設定ファイルで調整可能**にする（カメラの設置環境により最適値が異なるため）。

### 2.3 ライブビュー
- 現在のカメラ映像をウィンドウにリアルタイム表示する機能を持つ。

### 2.4 通知
- 検知時の外部通知（デスクトップ通知/メール等）は**MVPでは実装しない**。録画のみで記録を残す。

### 2.5 起動・操作
- GUI常駐やシステムトレイ常駐は行わず、**コマンドラインから手動で起動・停止**する
  （`uv run python` を想定）。

## 3. 非機能要件

### 3.1 保存期間・ストレージ管理
- 録画データの保持期間は**7日間**とする。
- 7日を超えた録画ファイルは自動的に削除する。

### 3.2 異常系
- カメラ切断時、ディスク容量不足時にアプリがクラッシュせず、エラーとして検知・記録できること
  （詳細な挙動は設計フェーズで定める）。

## 4. スコープ外（将来検討事項）
- 複数カメラ対応
- 検知時の外部通知（デスクトップ/メール等）
- システムトレイ常駐・GUI操作
- 保持期間や検知感度の動的変更（UIからの変更）

## 5. 合意状況
上記はユーザーへのヒアリング結果に基づき合意済み。次フェーズ（設計）にて、
技術選定・アーキテクチャ・データ設計・異常系の具体的な挙動を検討する。
